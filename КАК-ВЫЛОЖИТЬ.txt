КАК ДАТЬ ПОЧИТАТЬ
================

Эта папка — и запасная копия, и сайт для читателей.
Картинки лежат в media. Текст — в story.json и в index.html.

Читать у себя
-------------
Открой index.html двойным щелчком. Нужен интернет не нужен.
Либо пришли человеку весь архив: он распакует и откроет index.html.

Вернуть в мастерскую
--------------------
В Кадре на первой странице нажми «Открыть с диска» и выбери эту папку
или скачанный архив. История снова появится в программе, даже если
браузер почистили.

Выложить на GitHub, чтобы открывалось по ссылке
------------------------------------------------
1. Зайди на https://github.com и заведи аккаунт, если его нет.
2. Справа сверху «+» → New repository.
3. Имя, например, moya-novella. Public. Галочку README не ставь. Create.
4. «uploading an existing file» или Add file → Upload files.
   Перетащи сюда index.html, story.json, папку media и этот txt.
   Commit changes.
5. Settings → Pages → Branch: main, folder: / (root) → Save.
6. Подожди минуту. Ссылка будет такой:
   https://ТВОЙ-НИК.github.io/moya-novella/
   Её можно прислать кому угодно. Они читают в браузере, Кадр им не нужен.

Я сам на твой GitHub зайти не могу: это твой аккаунт.
Папка на диске как раз для того, чтобы ты выкладывала её сама
и не зависела от памяти браузера.
